# KouKi's 赌场（Casino）

单文件网页赌场：14 台机台 + 完整玩家钱包／贷款系统。全部逻辑都在 `index.html` 里，零依赖、离线可玩。

## 改版规则（重要・长期有效）

> **功能／内容类更新必须电脑端与手机端同步生效。**
> 只有「手机独占」内容可以只写在手机媒体查询里。

| 必须两端同步（写在全局） | 可以只写手机端（写在 @media 里） |
| --- | --- |
| 图标 / SVG symbol、文字与台词 | 触摸逻辑（`touch-action`、长按撤单、手势抑制） |
| 赔率、概率（如救济金 70%）、破产线、贷款、签到 | 尺寸与布局（宽度、字号、列数、间距、横屏、安全区） |
| 看板娘好感度与对话、救济金强制弹窗 | 省电与画质（DPR、阴影、模糊、动画降频） |
| 玩法与结算逻辑、钱包账目 | 手机专属的贴边定位、最大高度与滚动 |

每次改完跑一遍 `node test/synccheck.js`：它会解析 `index.html` 的 CSS/JS，断言
① 功能类规则没有落在手机媒体查询里；② 触摸/尺寸类规则没有泄漏到全局；
③ 图标、概率、好感度等常量只有一份（两端共用）。当前 46/46 通过。

## 运行方式

**方式一：直接打开**

双击 `index.html`（或拖进浏览器）即可。存档写在浏览器 `localStorage`；用 `file://` 打开时部分浏览器会禁用本地存储，此时游戏照常能玩，但刷新后存档不会保留。

**方式二：当网站跑（推荐）**

```bash
node server.js            # 默认 http://localhost:8080/
$env:PORT=3000; node server.js   # PowerShell 换端口
```

浏览器打开 `http://localhost:8080/` 即可，存档与签到状态会按浏览器持久保存。

## 玩家账户规则

| 项目 | 数值 |
| --- | --- |
| 初始资金 | **$500** |
| 贷款额度 | **$5,000**（无利息，随借随还，还清额度恢复） |
| 每日签到 | **$1,000**（每个自然日一次，按网站时间 00:00 刷新） |
| 破产救济金 | **$100**，触发概率 **70%** |
| 自动还贷 | 有负债时，每次进账的 **10%** 自动还贷 |

补充说明：

- 「进账」包括：赢利、机台兑现、签到、救济金。**押注退回与和局退本金不算进账**，不会被扣 10%。
- 派彩只按**赢利**扣 10%（例如押 $100 中 $250，赢利 $150，还贷 $15），不会动到你的本金。
- **救济金不会连续触发**：触发后需要先再次获得金钱（非救济金），之后再次破产才会重新回到 70% 判定；70% 未中时保持就绪，下次破产可再判定。
- 破产判定 = **钱包现金 ＋ 贷款还能借的额度 ≤ $10**（机台在场余额为 0 时才结算判定）。

## 夜之角 ・ 三张桌子（2026-09-27 追加）

「夜之角」是沙耶守着的小厅，目前有三张桌子，入口在页签「六弹舱 / 炸金花 / 手指刀锋」与大堂卡片上。

### 炸金花（三张牌）

- **4 人桌**（你 + 3 位 AI），每人先交底注，再各发 3 张暗牌。
- 牌型：**豹子 ＞ 同花顺 ＞ 同花 ＞ 顺子 ＞ 对子 ＞ 散牌**；同型比点数，点数相同比花色（♠＞♥＞♦＞♣）。
- 顺子：**A23 最小 → 234 → … → QKA 最大**；特殊规则 **235 不同花可以赢豹子**。
- **闷牌**（未看牌）跟注只要 1 注；**看牌**后跟注要 2 注（下注翻倍）。
- **比牌**：花当前注额指定一名对手摊牌，输的一方当场出局（平局时发起方输）。
- 只剩一人在场直接收池；AI 筹码跨局累积，快见底才补，不会凭空造钱。

### 手指刀锋（Five Finger Fillet）

- 美式酒吧把戏：落刀点沿 `左外→1→2→3→4→右外→4→3→2→1` 来回走，**共 10 刀**。
- 每刀倍率依次 **×1.5 / ×2 / ×2.7 / ×3.5 / ×4.5 / ×5.7 / ×7.2 / ×9 / ×11.5 / ×50**。
- 指针扫到亮起的格子时按「扎！」（键盘空格同效），**失手 = 本金全输**；任何时候可以「收手结算」按当前倍率拿走。
- 难度随刀数递增：每刀速度 +0.32，但判定容差也从 40% 逐步放宽到 60%（`filTol()`），所以后面几刀靠的是手稳而不是手快。

## 独立机台的兑现

柏青哥（球）、老虎机（メダル）、转盘机（分数）是独立机台：

- 用钱包现金「借球／借メダル／上分」，玩剩的可以在机台上按「**兑现**」换回现金；
- **离开机台时会自动兑现**，钱不会卡在机台上；
- 买入与兑现同价（按实际数量计费），不存在低买高卖。
- 柏青哥的「练习（无限球）」完全免费、不计现金，适合先练手感。

触屏专属操作：

- **长按注区 = 右键撤单**（带位移取消判定，触发后吞掉随后的点击，不会误押注）
- 手机默认**收起看板娘**，只留底部按钮条，不挡机台；点「展开」可还原
- canvas 全部 `touch-action:none`，拖发射旋钮／转盘不会连带页面滚动

### 触摸与滚动（2026-09-27 更新）

- `html,body{touch-action:manipulation}`：**全页禁用双击放大**，画布仍由 `canvas{touch-action:none}` 覆盖，所以拖旋钮／转盘不受影响
- 手机端移除 `background-attachment:fixed` 与大面积 `blur()`（iOS 上滚动会逐帧重绘），并加 `overscroll-behavior-y:contain`，上下滑动更跟手
- 看板娘对话框改为 `pointer-events:none`（不吃点击）＋贴底半透明＋说完自动收起，不会挡住下注区；救济金说明可点掉

### 手机端专项修复（2026-09-27）

| 问题 | 根因 | 修法 |

## 渲染性能（手机不发热的关键）

`window.ENGINE` 统一帧调度器把所有机台的 `requestAnimationFrame` 收进一个循环：

| 措施 | 效果 |
| --- | --- |
| 没有任何机台在动时停止调度 | 大厅／看规则时 **0 次绘制/帧**，页面可以真正 idle |
| 切到后台立刻停表 | 不会在后台偷偷跑满帧 |
| 空闲机台降到 30fps | 待机功耗减半；一旦开转／发球立即回到 60fps |
| 手机画布像素比降到 1.25 | 相对 DPR2 的像素量降到 **39%** |
| 低画质关闭 `shadowBlur` | 阴影模糊是移动端最贵的绘制操作（每次 fill 都要高斯模糊），11 处全部改走 `FX()` 开关 |
| 低画质粒子减半 | 弹珠火花粒子数量减半并加上限 |
| 停掉 `filter` 动画与 `backdrop-filter` | `neon` 的 brightness 滤镜与顶栏毛玻璃都会持续重绘整块区域 |
| 静态层烘焙 | 柏青哥场地（32 个渐变）转盘盘面、轮盘 38 格、老虎机 7 种图案各烘焙一次 |
| 批量描边 | 钉子 437 颗合成 2 条路径；导轨按颜色合批；灯珠亮/暗各 1 条路径 |
| 音频限流 | 16ms 内不重复发声，避免移动端音频线程过载 |
| 自适应画质 | 绘制耗时连续 >13ms 自动降档（关装饰细节、减少物理子步） |

实测每帧「填充/描边」次数（`node test/perftest.js`，越低越省电）：

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 大厅空闲 | 持续 60fps 空转 | **0**（完全停帧） |
| 柏青哥（空盘 / 10 球在飞） | ~2000 / ~2100 | **81 / 117** |
| 老虎机（待机 / 回転中） | 119 / 246 | **74 / 105** |
| 转盘机（转动中） | 226 | **65** |
| 轮盘（转动中） | 120 | **7** |
| 六弹舱（击发中） | 20 | 20 |

同一段 4000 帧的柏青哥自动模拟，总 canvas 调用数从 7,614,389 降到 3,849,262（约 −49%）。
